# Sign up & Onboarding Improvement for a Personal Finance Software \- To Reduce Friction & Improve Userflow

Created UI consistency for Quicken Deluxe. **Simplified onboarding screens to ease the complexity.** 

Problems: 1\) Quicken used 2 brand colours and UI treatments for their new and old products, which confused the users. 2\) Quicken’s Sign up & Onboarding process included ineffective complex screen shots that relied too much on the user's memory. 

This was a passion project, I teamed up with another Sr. UX designer and together we built a case to Improved Quicken’s: **brand consistency**, **sign up** and **onboarding process**.

**About Quicken**

Quicken, **is a personal finance software** serving US and Canadian users.

## **We ran a UX audit and noticed 3 major issues** 

1. **Brand inconsistency** for the old and new product.   
2. Interruption in the user flow and a **poor sign up flow**.  
3. **Complex screen shots for onboarding new users**.

## **The First Problem \- Brand Inconsistency Creating Confusion** The Blue and Red logos created confusion for the users to understand the service offerings

Quicken’s brand colour used to be red. Once they launched Quicken Simlifi (which is a light version of the software for Web), they rebranded to Blue. However they kept the red brand colour for their original product (called Quicken Classic). 

This is confusing for the users as **they don’t know the difference between the two products but experience limitations and sync issues**, once they start to use them.

 \[IMAGE OF THE 2 LOGOS\]

**Confusion for Canadian users**

We will now look at some issues in the sign up process that are caused by this problem plus more UX issues that interrupt the new user’s flow.  
Quicken Classic is the only version available to Canadian users. However, the website uses UI design elements from the new version (Quicken Simplifi), while advertising packages from Quicken Classic. **This is confusing to the user** as they see the Quicken Logo with 2 different UI treatments **and will interrupt the new user’s flow.**

\[IMAGE OF OLD THE PLAN & PRICING- Desktop\]

## **UI Solution to Resolve this Issue**  Use the new brand Logo and UI treatment everywhere on the site. Use the package names to differentiate it from Quicken Simplifi. Add appropriate details about the benefits of each package.

**The Second Problem \- Interruption In the Onboarding Flow**  
After choosing a package, when a user is trying to sign up for the first time, the second onboarding screen has 3 issues.   
1\) An incorrect message    
2\) Repeated ask for user’s email   
3\) An incorrect prioritized CTA  
Causing an interruption in the user’s onboarding flow. It looks like the second screen was not designed for first time users.  
\[IMAGE OF THE CURRENT STATE\]

## **UX Improvements to the Onboarding Flow**

We dedicated a page to first time users who are trying to create an account and onboard. 

* Change the messaging   
* Include only one Button   
* Remove repeated step (asking for email twice)

\[IMAG OF THE IMPROVED STATE\]

## **Lack of clear communication in software adoption**  After the user completes creating an account and paying, the Web browser suggests downloading the software on their computer. VERY CLEAR 👏🏼.  However, if the user decides to go to her account and double check her personal info, (as many new users do), when they click ‘My account’ the information about Quicken Simplifi shows up at the bottom. **Once again the brand inconstancy between Red & Blue can confuse the new user**, not knowing which one to get.   **UI Improvements to the Adoption Flow** 

* **Use a consistent brand colour for both versions**. Differentiate them only based on the packages that will fall under each version.   
* Make the Classic option the only one available for download as Quicken Simplifi does not work for Canadians.   
* Do not provide options to download Quicken Simplifi for a user who has just signed up for Quicken Classic (as this will be confusing for them).

## **The Third Problem \- Overwhelming Screnn shots on the intro screen**

User is presented with a lot of information, it’s hard to focus their attention on a specific area and it’s not the best way to teach them how to use the software. 

**\[IMAG OF THE INTRO SCREENS\]**

## **2 UX approaches to fix the issue:**

**Instead of asking user to learn & remember Quicken, we will guide them on each step**

* How to add their accounts minus all the extra info that is not necessary at this stage.  
* Redesign the dashboard to make it more digestible, organized, and delightful to use.

**Approach to Iterations**

* Simplify the screens by covering the text details  
* Add interaction on slides (like a Gif)  
* Break down the content instead of novelizing  
* Add hierarchy of info, using different type size and weight to focus the user’s attention.  
* Redesign dashboard
